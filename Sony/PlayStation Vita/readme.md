While [Henkaku Enso](https://enso.henkaku.xyz) is the persistent CFW, the temporary [Henkaku](https://henkaku.xyz) has to be installed first to allow the installation of Enso.

Henkaku comes with MolecularShell, which is a file manager similar to [VitaShell](https://github.com/theofficialflow/vitashell), which is an advanced version can be installed via MolecularShell. Then the .vpk package of Henkaku Enso can then be installed via MolecularShell or VitaShell.
