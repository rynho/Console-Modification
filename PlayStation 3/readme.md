The main CFW at the moment is Evilnat, recent update [4.93 here](https://www.psx-place.com/resources/4-93-evilnat-cobra-8-5.1479/).

### Key Features
- Cobra Payload: Built-in Cobra extensions (such as Cobra v8.5) expand system capabilities like mounting ISO backups, custom plugins, and direct management.
- Permanent Jailbreak: Unlike HEN (Homebrew Enabler), Evilnat CFW stays active permanently after a system reboot.
- Overclocking & Tools: Includes the xai_plugin suite for on-the-fly overclocking, fan control, and PS2 emulation adjustments.
- Direct Updates: Newer versions allow direct system updates over the internet straight from the XMB interface after initial setup.
- Multiple Flavors: Offered in variants like CEX, PEX, D-PEX, and DEX depending on whether the user is running retail or development environments.
