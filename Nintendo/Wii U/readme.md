While Wii U don't have a persistent Custom Firmware (CFW) available, the payload loader can be configured to load the CFW environment at every boot and behave persistently from user perspective.

[Aroma](https://github.com/wiiu-env/Aroma) is a popular CFW environment, which can be installed following the instruction on [Wii Hacks Guide](https://wii.hacks.guide/).
